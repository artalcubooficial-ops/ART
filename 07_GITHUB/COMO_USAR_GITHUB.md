# Cómo usar esta carpeta con GitHub

## Qué se sube

- Tema Shopify sincronizado.
- Documentación de `03_DOCUMENTOS`.
- Datos no sensibles de `04_DATOS`.
- Fotos necesarias para el proyecto, si su tamaño y licencia lo permiten.

## Qué no se sube

- Contraseñas, tokens, cookies o credenciales.
- Archivos `.env`.
- Datos de clientes.
- Temporales, cachés y respaldos duplicados.

## Flujo sencillo

1. Trabajar en local.
2. Probar en un tema de desarrollo de Shopify.
3. Guardar una versión en Git.
4. Subir la versión aprobada a GitHub.
5. El otro Codex clona el repositorio y lee `PROJECT_HANDOFF.md`.

GitHub guarda el código y los archivos; no reemplaza la autorización independiente de Shopify.
