# Arquitectura de pagos

El tema usa el carrito y checkout nativos de Shopify. No se implementa un checkout paralelo ni se exponen datos bancarios.

El flujo de abono + saldo contraentrega requiere validar una aplicación o configuración real de Shopify Payments/COD y sus costos. No se instala ni se activa una aplicación de pago sin autorización del propietario y sin revisar compatibilidad con ART³ CONTROL.

Pendiente humano: confirmar pasarela, si el abono aplica a todas las referencias y reglas legales/comerciales de contraentrega.
