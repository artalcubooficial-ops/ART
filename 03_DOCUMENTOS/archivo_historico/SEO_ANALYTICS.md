# SEO y analítica

## Preparado en el tema

- `title` y description dinámicos.
- URL canonical.
- Open Graph básico.
- Imagen OG cuando Shopify expone `page_image`.
- Datos estructurados de producto mediante `structured_data` de Shopify.
- ALT derivado de títulos de producto en las galerías.

## Pendiente de configuración humana

- Google Analytics 4.
- Meta Pixel/Conversions API.
- TikTok Pixel.
- IDs de Google Search Console y Merchant Center.
- UTMs de campañas.

No se inventan IDs ni se activan scripts de seguimiento sin autorización y credenciales del propietario.
