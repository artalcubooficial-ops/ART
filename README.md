# ART³ — Proyecto original

Esta es la carpeta de trabajo organizada de la tienda ART³.

## Regla principal

- `01_TEMA_SHOPIFY/` contiene el tema sincronizado con Shopify.
- `02_FOTOS/` contiene las imágenes originales y las portadas/carruseles.
- `03_DOCUMENTOS/` contiene reglas, manuales y notas del proyecto.
- `04_DATOS/` contiene exportaciones y tablas de referencia.
- `05_RESPALDOS/` contiene copias históricas; no se editan.
- `06_TRABAJO_EN_CURSO/` contiene cambios temporales antes de aprobarlos.
- `07_GITHUB/` contiene instrucciones para versionar y subir el proyecto.

La carpeta antigua `C:\Users\USER\Desktop\proyecto art` se conserva intacta como archivo histórico hasta verificar toda la sincronización.

## Fuente de verdad

Antes de editar, hay que sincronizar el tema activo desde Shopify. Los archivos locales anteriores no se consideran automáticamente iguales a lo que está publicado.

## Productos intocables

PM-OS-01, PM-OS-02, PM-OS-03, PM-OS-04 y PM-OS-05 no deben modificarse mientras se trabaja en PM-OS-06.
